
# JavaScript Shopping Receipt Calculator

## Description
This project is a supermarket shopping receipt calculator built using JavaScript.

## Features
- Calculates individual product totals and subtotal.
- Applies a 10% discount when the subtotal is at least 20,000 RWF.
- Calculates 18% VAT after the discount.
- Converts customer age and payment from strings to numbers.
- Formats the customer's name and initials.
- Displays a formatted shopping receipt.
- Calculates customer change or remaining balance.
- Displays a message when payment is insufficient.

## Technologies
- JavaScript
- Node.js
- Visual Studio Code

## How to Run
1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   `node shopping-receipt.js`

5. View the receipt in the terminal.

## Concepts Practiced
Variables, strings, numbers, booleans, arithmetic operators, comparison operators, logical operators, type conversion, string methods, template literals, and conditional statements.
